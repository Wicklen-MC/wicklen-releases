# Wicklen — файлы выпусков

Публичные скачивания сборки Wicklen, собственного компата и ресурспаков для Minecraft 26.3.

- [Обновления и все файлы по версиям](https://wicklen.link/updates.html)
- [Справочник модов](https://wicklen.link/handbook.html)
- [Гайды, включая Compat](https://wicklen.link/guides.html)
- [Сборка 0.5.0](https://github.com/Wicklen-MC/wicklen-releases/releases/tag/pack-v0.5.0)
- [Compat 0.1.2](https://github.com/Wicklen-MC/wicklen-releases/releases/tag/compat-v0.1.2)
- [Русский перевод и модели 0.5.0](https://github.com/Wicklen-MC/wicklen-releases/releases/tag/resources-v0.5.0)

Полные клиентские и серверные ZIP хранятся на downloads.wicklen.link; ссылки, манифесты и контрольные суммы есть в каждом выпуске. Старые файлы сохраняются без перезаписи.

На игровом сервере пока установлена сборка 0.4.5. Публикация новой версии и её применение на сервере выполняются отдельно.
